A simple command-line Python application that performs basic CRUD operations (Create, Read, Update, Delete) on text files.

Features
Create a new file and write data to it
Read the contents of an existing file
Update the contents of an existing file
Delete an existing file
Usage
Run the script and choose an option from the menu:

bash
python main.py
press 1 to create file
press 2 to read file
press 3 to update file
press 4 to delete file
Follow the prompts to enter the file name and data.

Files
main.py – core CRUD logic and menu
file_crud.py – supporting file operations
crud-file-under-25mb.exe – standalone Windows executable version made using generative ai
